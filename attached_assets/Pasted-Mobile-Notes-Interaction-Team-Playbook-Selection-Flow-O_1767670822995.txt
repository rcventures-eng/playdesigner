Mobile Notes Interaction & Team Playbook Selection Flow
Overview
Implement the following features on BOTH desktop and mobile versions of the RC Football app:

Mobile notes: drag to move, long-press menu for delete/resize, pinch-to-resize
Team Playbook: single-click highlights with trash icon, double-click opens in view-only mode


Feature 1: Mobile Notes - Move, Delete, Resize
Problem: On mobile web, notes cannot be moved around the screen like players can. There's no way to delete or resize notes on mobile.
Fix Required:
Part A: Drag to Move Notes
Notes should be movable by touch-dragging, similar to how players are moved.
typescriptconst [draggingNoteId, setDraggingNoteId] = useState<string | null>(null);
const [noteOffset, setNoteOffset] = useState({ x: 0, y: 0 });

const handleNotePointerDown = (e: PointerEvent, noteId: string) => {
  const note = notes.find(n => n.id === noteId);
  if (!note) return;
  
  // Calculate offset from touch point to note position
  const rect = (e.target as HTMLElement).getBoundingClientRect();
  setNoteOffset({
    x: e.clientX - rect.left,
    y: e.clientY - rect.top
  });
  
  setDraggingNoteId(noteId);
  
  // Capture pointer for smooth dragging
  (e.target as HTMLElement).setPointerCapture(e.pointerId);
  
  // Lock scrolling while dragging
  document.body.style.overflow = 'hidden';
  document.body.style.touchAction = 'none';
};

const handleNotePointerMove = (e: PointerEvent) => {
  if (!draggingNoteId) return;
  
  e.preventDefault();
  
  // Calculate new position relative to canvas
  const canvas = document.querySelector('.field-canvas');
  const canvasRect = canvas?.getBoundingClientRect();
  if (!canvasRect) return;
  
  const newX = e.clientX - canvasRect.left - noteOffset.x;
  const newY = e.clientY - canvasRect.top - noteOffset.y;
  
  // Update note position
  setNotes(notes.map(n => 
    n.id === draggingNoteId 
      ? { ...n, x: newX, y: newY }
      : n
  ));
};

const handleNotePointerUp = (e: PointerEvent) => {
  if (draggingNoteId) {
    (e.target as HTMLElement).releasePointerCapture(e.pointerId);
    setDraggingNoteId(null);
    
    // Restore scrolling
    document.body.style.overflow = '';
    document.body.style.touchAction = '';
  }
};

Part C: Pinch-to-Resize
When "Resize" is selected from the menu, enable pinch gesture to adjust note size.
Implementation:
typescriptconst [resizingNoteId, setResizingNoteId] = useState<string | null>(null);
const [initialPinchDistance, setInitialPinchDistance] = useState<number | null>(null);
const [initialNoteSize, setInitialNoteSize] = useState({ width: 0, height: 0 });

const handleResizeMode = (noteId: string) => {
  setResizingNoteId(noteId);
  const note = notes.find(n => n.id === noteId);
  if (note) {
    setInitialNoteSize({ width: note.width || 120, height: note.height || 60 });
  }
  
  // Show resize indicator
  showToast('Pinch to resize note');
};

const handleTouchStart = (e: TouchEvent) => {
  if (!resizingNoteId) return;
  
  if (e.touches.length === 2) {
    // Two fingers - start pinch
    const distance = getPinchDistance(e.touches);
    setInitialPinchDistance(distance);
  }
};

const handleTouchMove = (e: TouchEvent) => {
  if (!resizingNoteId || !initialPinchDistance) return;
  
  if (e.touches.length === 2) {
    e.preventDefault();
    
    const currentDistance = getPinchDistance(e.touches);
    const scale = currentDistance / initialPinchDistance;
    
    // Calculate new size with constraints
    const newWidth = Math.max(60, Math.min(300, initialNoteSize.width * scale));
    const newHeight = Math.max(40, Math.min(200, initialNoteSize.height * scale));
    
    setNotes(notes.map(n =>
      n.id === resizingNoteId
        ? { ...n, width: newWidth, height: newHeight }
        : n
    ));
  }
};

const handleTouchEnd = (e: TouchEvent) => {
  if (resizingNoteId && e.touches.length < 2) {
    // Pinch ended
    setInitialPinchDistance(null);
    setResizingNoteId(null);
  }
};

// Helper function
const getPinchDistance = (touches: TouchList): number => {
  const dx = touches[0].clientX - touches[1].clientX;
  const dy = touches[0].clientY - touches[1].clientY;
  return Math.sqrt(dx * dx + dy * dy);
};

Feature 2: Team Playbook - Selection Highlight & View-Only Mode
Problem: Single-clicking a play in Team Playbook doesn't highlight it. Double-clicking should open the play in view-only mode.
Fix Required:
Part A: Single-Click - Orange Highlight with Trash Icon
When a play is single-clicked:

Apply orange border/background highlight to the play card
Show trash icon on the RIGHT side of the card

Implementation:
typescriptconst [selectedPlayId, setSelectedPlayId] = useState<string | null>(null);
const [lastClickTime, setLastClickTime] = useState<number>(0);
const [lastClickedId, setLastClickedId] = useState<string | null>(null);

const DOUBLE_CLICK_THRESHOLD = 300; // ms

const handlePlayClick = (playId: string) => {
  const now = Date.now();
  
  // Check for double-click
  if (lastClickedId === playId && (now - lastClickTime) < DOUBLE_CLICK_THRESHOLD) {
    // Double-click detected
    handlePlayDoubleClick(playId);
    setLastClickTime(0);
    setLastClickedId(null);
    return;
  }
  
  // Single-click - select and highlight
  setSelectedPlayId(playId);
  setLastClickTime(now);
  setLastClickedId(playId);
};

const handleDeletePlay = (playId: string, e: React.MouseEvent) => {
  e.stopPropagation();
  
  if (confirm('Remove this play from the playbook?')) {
    deleteFromPlaybook(currentPlaybookId, playId);
    setSelectedPlayId(null);
  }
};

Part B: Double-Click - Open in View-Only Mode
When a play is double-clicked:

Navigate to the Play Designer
Load the play in view-only mode (no editing allowed)
Show a banner/message above the canvas indicating view-only mode

Implementation:
