Issue 2: Player Dragging Still Conflicts with Field Scroll (CRITICAL)
Problem: When dragging a player on mobile, the field frequently scrolls instead of moving the player. This makes the app nearly unusable for play design on touch devices.
This is a major UX flaw that will torpedo usage if not fixed.
Fix Required — Implement Aggressive Touch Isolation:

On pointer/touch down on a player:

typescriptconst handlePlayerPointerDown = (e: PointerEvent, playerId: string) => {
  e.preventDefault();
  e.stopPropagation();
  
  // Capture all pointer events to this element
  (e.target as HTMLElement).setPointerCapture(e.pointerId);
  
  // Disable ALL touch/scroll behavior on parent containers
  document.body.style.overflow = 'hidden';
  document.body.style.touchAction = 'none';
  
  const fieldContainer = document.querySelector('.field-container');
  if (fieldContainer) {
    fieldContainer.style.overflow = 'hidden';
    fieldContainer.style.touchAction = 'none';
  }
  
  setActivePlayer(playerId);
  setIsDragging(true);
};

On pointer/touch up or cancel:

typescriptconst handlePlayerPointerUp = (e: PointerEvent) => {
  // Release pointer capture
  (e.target as HTMLElement).releasePointerCapture(e.pointerId);
  
  // Re-enable scroll behavior
  document.body.style.overflow = '';
  document.body.style.touchAction = '';
  
  const fieldContainer = document.querySelector('.field-container');
  if (fieldContainer) {
    fieldContainer.style.overflow = '';
    fieldContainer.style.touchAction = '';
  }
  
  setIsDragging(false);
  setActivePlayer(null);
};

Add CSS to player elements:

css.player-circle {
  touch-action: none;
  user-select: none;
  -webkit-user-select: none;
}

Consider a "drag mode" indicator — when a player is being dragged, show a subtle visual cue (slight scale up, shadow, or border) so user knows they're in drag mode.
Add pointercancel handler to clean up state if the drag is interrupted.

typescriptconst handleSharePlay = async () => {
  // Generate PNG image of the play
  const playImage = await renderPlayToImage(playState);
  
  // Convert to blob
  const blob = await fetch(playImage).then(r => r.blob());
  const file = new File([blob], 'play.png', { type: 'image/png' });
  
  // Use Web Share API (works on iOS and Android)
  if (navigator.share && navigator.canShare({ files: [file] })) {
    await navigator.share({
      title: playName || 'Football Play',
      text: 'Check out this play I designed!',
      files: [file]
    });
  } else {
    // Fallback: download the image
    const link = document.createElement('a');
    link.href = playImage;
    link.download = `${playName || 'play'}.png`;
    link.click();
  }
};
