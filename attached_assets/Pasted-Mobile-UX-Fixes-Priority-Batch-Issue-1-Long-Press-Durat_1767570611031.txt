Issue 2: Player Dragging Conflicts with Field Scroll
Problem: When dragging a player with a finger, the player often stops moving and the field scrolls instead. This makes repositioning players extremely frustrating on mobile.
Fix Required:

When a player drag starts, freeze all scroll behavior on the field container until the drag completes
Implement touch event isolation:

typescriptconst handlePlayerDragStart = (e: PointerEvent, playerId: string) => {
  e.preventDefault();
  e.stopPropagation();
  
  // Capture pointer to this element
  (e.target as HTMLElement).setPointerCapture(e.pointerId);
  
  // Disable scroll on the field container
  fieldContainerRef.current.style.overflow = 'hidden';
  fieldContainerRef.current.style.touchAction = 'none';
  
  setDraggingPlayer(playerId);
};

const handlePlayerDragEnd = (e: PointerEvent) => {
  // Re-enable scroll
  fieldContainerRef.current.style.overflow = 'auto';
  fieldContainerRef.current.style.touchAction = 'auto';
  
  // Release pointer capture
  (e.target as HTMLElement).releasePointerCapture(e.pointerId);
  
  setDraggingPlayer(null);
};

Additionally, add touch-action: none CSS to player circles to prevent browser touch handling
The scroll should ONLY be re-enabled after the finger is lifted (pointerup/pointercancel)
