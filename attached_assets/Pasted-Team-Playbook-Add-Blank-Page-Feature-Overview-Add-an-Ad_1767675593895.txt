Team Playbook - Add Blank Page Feature
Overview
Add an "Add Blank Page" feature to the Team Playbooks section on BOTH desktop and mobile. This allows coaches to insert blank divider pages into their playbooks that can be customized later or used as section separators (e.g., between offensive and defensive plays, or between different formations).

Feature Requirements
Button Placement
Add an "Add Blank Page" button in the Team Playbooks header area, positioned to the far right of the text/title area.
Desktop Layout:
┌─────────────────────────────────────────────────────────────────────────────┐
│ Team Playbook: [Playbook Name]                      [+ Add Blank Page]     │
├─────────────────────────────────────────────────────────────────────────────┤
│ Play 1 | Play 2 | Blank Page 1 | Play 3 | Blank Page 2 | Play 4 | ...     │
└─────────────────────────────────────────────────────────────────────────────┘
Mobile Layout:
┌────────────────────────────────────────┐
│ Team Playbook              [+ Blank]   │
├────────────────────────────────────────┤
│ ...                                    │
└────────────────────────────────────────┘
Naming Convention

First blank page: "Blank Page 1"
Second blank page: "Blank Page 2"
And so on...
No limit on the number of blank pages

The numbering should be based on the COUNT of existing blank pages in that specific playbook, not a global counter.

Calculate Next Blank Page Number
typescriptconst getNextBlankPageNumber = (playbookEntries: PlaybookEntry[]): number => {
  // Filter to only blank pages in this playbook
  const blankPages = playbookEntries.filter(entry => entry.type === 'blank');
  
  if (blankPages.length === 0) {
    return 1;
  }
  
  // Find the highest existing number
  const existingNumbers = blankPages.map(page => {
    const match = page.blankPageTitle?.match(/Blank Page (\d+)/);
    return match ? parseInt(match[1], 10) : 0;
  });
  
  const maxNumber = Math.max(...existingNumbers);
  return maxNumber + 1;
};
API Endpoint
typescript// POST /api/playbooks/:playbookId/blank-page
app.post('/api/playbooks/:playbookId/blank-page', async (req, res) => {
  const { playbookId } = req.params;
  const userId = req.user.id;
  
  // Verify user owns this playbook
  const playbook = await db.query.playbooks.findFirst({
    where: and(
      eq(playbooks.id, playbookId),
      eq(playbooks.userId, userId)
    )
  });
  
  if (!playbook) {
    return res.status(404).json({ error: 'Playbook not found' });
  }
  
  // Get existing entries to calculate position and blank page number
  const existingEntries = await db.query.playbookEntries.findMany({
    where: eq(playbookEntries.playbookId, playbookId),
    orderBy: desc(playbookEntries.position)
  });
  
  const blankPages = existingEntries.filter(e => e.type === 'blank');
  const nextNumber = getNextBlankPageNumber(blankPages);
  const nextPosition = existingEntries.length > 0 
    ? existingEntries[0].position + 1 
    : 0;
  
  // Create blank page entry
  const newEntry = await db.insert(playbookEntries).values({
    id: generateId(),
    playbookId,
    playId: null,
    type: 'blank',
    blankPageTitle: `Blank Page ${nextNumber}`,
    position: nextPosition,
    createdAt: new Date().toISOString(),
    updatedAt: new Date().toISOString()
  }).returning();
  
  res.json(newEntry[0]);
});

const BlankPageEditor = ({ entry, onSave, onClose }) => {

Google Drive Sync Integration
When syncing the playbook to Google Drive, blank pages should be included as actual pages in the exported document/PDF.
typescriptconst syncPlaybookToGoogleDrive = async (playbookId: string) => {
  const entries = await getPlaybookEntries(playbookId);
  
  // Build document pages in order
  const pages = entries.map((entry, index) => {
    if (entry.type === 'blank') {
      // Create a blank/divider page
      return {
        type: 'divider',
        title: entry.blankPageTitle,
        content: entry.customContent || '',
        pageNumber: index + 1
      };
    } else {
      // Create a play page
      return {
        type: 'play',
        playData: entry.play,
        pageNumber: index + 1
      };
    }
  });
  
  // Generate PDF/document with all pages including blanks
  const document = await generatePlaybookDocument(pages);
  
  // Upload to Google Drive
  await uploadToGoogleDrive(document);
};

// When generating the document/PDF
const generatePlaybookDocument = async (pages: Page[]) => {
  const doc = new PDFDocument();
  
  for (const page of pages) {
    if (page.type === 'divider') {
      // Add a divider/blank page
      doc.addPage();
      doc.fontSize(24).text(page.title, { align: 'center' });
      
      if (page.content) {
        doc.fontSize(14).text(page.content, { align: 'center' });
      }
    } else {
      // Add play page (existing logic)
      doc.addPage();
      await renderPlayToPage(doc, page.playData);
    }
  }
  
  return doc;
};
