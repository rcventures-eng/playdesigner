Issue B: Save to Photos with Watermark by Default
Problem: Tapping "Save" shows options for Files or Drive, but the expected behavior is to save directly to the Photos app (camera roll) with a subtle watermark.
Fix Required:

Change default save behavior — save directly to Photos, not Files/Drive picker:

typescriptconst handleSavePlay = async () => {
  // Generate the play image with watermark
  const playImage = await renderPlayToImageWithWatermark(playState);
  
  // On iOS/Android, use the share API to save to Photos
  const blob = await fetch(playImage).then(r => r.blob());
  const file = new File([blob], `${playName || 'play'}.png`, { type: 'image/png' });
  
  if (navigator.share && navigator.canShare({ files: [file] })) {
    // This will show native share sheet where user can "Save Image"
    await navigator.share({ files: [file] });
  } else {
    // Fallback: trigger download
    const link = document.createElement('a');
    link.href = playImage;
    link.download = `${playName || 'play'}.png`;
    link.click();
  }
};

Add watermark to exported image — modify the renderPlayToImage function (or create renderPlayToImageWithWatermark):

typescriptconst renderPlayToImageWithWatermark = async (playState) => {
  // Render play to canvas as usual
  const canvas = await renderPlayToCanvas(playState);
  const ctx = canvas.getContext('2d');
  
  // Add subtle watermark in bottom-right corner
  ctx.save();
  ctx.font = '10px -apple-system, BlinkMacSystemFont, sans-serif';
  ctx.fillStyle = 'rgba(255, 255, 255, 0.5)'; // Semi-transparent white
  ctx.textAlign = 'right';
  ctx.textBaseline = 'bottom';
  ctx.fillText('Built in RC Football', canvas.width - 8, canvas.height - 8);
  ctx.restore();
  
  return canvas.toDataURL('image/png');
};

Watermark styling:

Position: bottom-right corner, 8px padding from edges
Text: "Built in RC Football"
Color: semi-transparent white (rgba(255, 255, 255, 0.5)) for light visibility without being intrusive
Font size: 10px, system font
